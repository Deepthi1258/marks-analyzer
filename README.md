# Marks Analyzer

This is a Python project that analyzes student marks.

## Features
- Calculates total and average marks
- Finds highest and lowest marks
- Counts students above 80 and below 50
- Assigns grades (A, B, C, Fail)

## How to Run
Run the file using:
python marks_analyzer.py

## Sample Output
Enter marks: 75 82 90 60 88

----- RESULT -----
- Total Marks: 395
- Average: 79.0
- Highest: 90
- Lowest: 60
- Students above 80: 3
- Students below 50: 0
